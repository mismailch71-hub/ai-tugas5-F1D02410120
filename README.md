## 1. Topik dan Cara Menjalankan Program
Aplikasi sistem pakar ini mengambil topik mengenai penentuan status bahaya dan penanganan kebakaran pada lingkungan gedung atau pemukiman. Topik ini dipilih untuk memberikan penilaian awal kesiapsiagaan bencana berdasarkan indikator pemicu api serta kondisi perambatan api di lokasi kejadian. Program ini dikembangan menggunakan bahasa pemrograman java dengan memanfaatkan pustaka bawaan Java Swing untuk membangun antarmuka grafis (GUI) interatif. Untuk menjalankan aplikasi ini, sistem komputer memerlukan Java Development Kit (JDK) versi 11 atau versi yang lebih baru.
